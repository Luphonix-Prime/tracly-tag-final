## ⚙️ **Code Generation Logic (CRITICAL)**

### Must Generate **GS1 Standard DataMatrix String**

### ✅ Unit / Case Level (L1 / L2):

Format:

```
01 + GTIN
17 + Expiry Date (YYMMDD)
10 + Batch Number
<FNC1>
21 + Serial Number
```

Example:

```
01089012345678901726123110BTCH777<FNC1>21SN998877
```

---

### ✅ Shipper / Pallet Level (L3):

Use **SSCC (AI 00)**:

```
00 + 18-digit SSCC
```

Example:

```
00189012345678901234
```

---

## ⚠️ Important Rules:

1. **No brackets stored in DB**
2. Store only RAW STRING
3. `<FNC1>` = ASCII 232 separator
4. Expiry format = YYMMDD
5. GTIN & SSCC check digit → GS1 Modulo 10
